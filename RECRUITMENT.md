# Looking for Contributors — PyPointer

Hello, everyone!

I'm the creator of **PyPointer**, an experimental Python library designed to bring C-style pointer concepts into Python.

The project currently supports:
- Pointer objects
- Reading and writing values through `.value`
- List and dictionary references
- Object attribute references
- Null pointers

I'm looking for people interested in helping develop the project!

You can contribute through:
- Implementing new features
- Writing tests
- Finding and fixing bugs
- Improving documentation

**Contribution rule:** All code contributions must be submitted through GitHub Pull Requests. Every PR will be reviewed before merging.

GitHub: https://github.com/Python-IDLE/PyPointer

If you're interested, feel free to check out the repository and introduce yourself in the public project discussions!

Thanks!
